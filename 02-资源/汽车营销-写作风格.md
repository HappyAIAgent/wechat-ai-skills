# 汽车营销写作风格规范（车评/新车上市）

适用场景：`wechat-car-writer` 技能生成新车上市、车型导购、试驾体验类公众号文章。

> ⚠️ **示例数据免责说明**：本文档所有具体车型数字（如 8295P 芯片、6.39 万元起、405km 续航、快充 16 分钟等）**仅用于演示"怎么组织句子"**，它们来自零跑A05 的一次实际写作。**写作时必须用当前车型 spec-data.json（基准）+ sources.md 交叉校验后的数据，严禁照搬示例数字。**

## 核心原则

1. **参数是主角**：真实参数（价格、尺寸、动力、续航、配置）是文章信任感的来源。数字必须来自 `spec-data.json`（真实采集），**禁止编造参数**。拿不到的数据写"官方暂未公布"，不猜测。
2. **参数要"翻译"**：每个关键参数旁边配一句白话解读（"405km 续航，按每天通勤 30km 算，一周一充"），让不懂车的读者也能看懂。
3. **克制点评**：可以做产品逻辑分析（"零跑想用智能化下探打开小型车市场"），但不用"惊艳""颠覆""遥遥领先"这类营销形容词。
4. **不像 AI 写的**：句式长短交错，用具体场景代替抽象形容词，避免排比句堆砌。

## 文章结构（上市新闻型）

### 标题（信息密度优先）
格式：`车型 + 上市/发布动作 + 价格锚点 + 1-2 个核心卖点参数`

示例（参考真实爆款）：
- `零跑A05正式上市：售价6.39万元起，CLTC续航405km/510km，快充30%-80%仅16分钟，定位智能灵动精品轿车`
- `比亚迪海豹06 GT上市：11.68万起，最快3.9秒破百，纯电+插混双动力`

要点：价格必进标题；续航/加速/尺寸/智驾挑最亮眼的 1-2 个；标题就是一段信息摘要。

### 开头（直入主题，不铺垫）
```
8月11日，零跑汽车A系列第二款车型A05在杭州正式上市，共推出5款版型，售价6.39万元起。
```
- 时间 + 地点 + 事件 + 最低起售价，一句话说完
- 不写"重磅来袭""万众期待"这类空话

### 价格（表格 + 版型逻辑）
```
具体价格：
- 零跑A05 405舒享版售价6.39万元
- 405悦享版售价6.79万元
- 510悦享版售价7.59万元
- ...
```
- 每个版型一行，价格精确到分
- 补充一句版型差异逻辑："405 与 510 主要差在电池容量，高配可选激光雷达"

### 定位与背景（1-2 段）
- 官方定位 + 车系/平台背景（"继 A10 之后 A 平台第二款车"）
- 目标人群一句（"主要面向年轻及首购用户"）

### 核心参数（表格 + 解读双轨）
按这个顺序组织，每块都是"参数表 + 白话解读"：

1. **尺寸空间**：长宽高、轴距、后备厢容积、得房率 → "4200mm 车长配 2605mm 轴距，后排头部空间 965mm，小型车的身材中型车的空间"
2. **动力续航**：电机功率、电池容量、CLTC 续航、快充时间、电耗 → "30% 充到 80% 只要 16 分钟，一顿饭的功夫"
3. **智能座舱**：车机芯片、屏幕尺寸、音响、语音 → "8295P 芯片 + 14.6 英寸 2.5K 中控屏，支持可见即可说"
4. **智能驾驶**：芯片、激光雷达、辅助驾驶等级、功能数 → "高配带激光雷达，支持车位到车位，共 43 项功能"
5. **安全**：高强度钢占比、气囊、主动安全功能

参数呈现格式：
```markdown
| 项目 | 参数 |
|------|------|
| 长×宽×高 | 4200×1800×1560mm |
| 轴距 | 2605mm |
| CLTC续航 | 405km / 510km |
| 电机功率 | 70kW / 90kW |
| 电池容量 | 39.8kWh / 53kWh |
```
（表格放硬参数，表格下面紧跟一两句白话解读）

### 权益与政策（上市型必写）
- 限时权益清单 + 价值金额（"至高价值10680元 + 2年0息 + 四项终身免费质保"）
- 权益截止时间（"至2026年9月30日24:00"）——**必须写截止时间**，这是合规要求
- 加一句获取方式

### 结尾（收束 + 引导）
- 用产品逻辑收尾，不喊口号
- 可选：一句适合人群判断（"这台车适合谁：预算 7-9 万、想要智能体验的城市通勤用户"）
- 文末注明来源（"数据来源：官方发布会/汽车之家/懂车帝"）

## 合规红线（必读）

| 规则 | 说明 | 示例 |
|------|------|------|
| **能耗数据必须标工况** | 续航/油耗/电耗必须带 CLTC/NEDC/WLTC 标注 | ✅ "CLTC续航405km" ❌ "续航405km" |
| **价格注明口径** | 标注"指导价/上市价"，权益价与指导价区分 | "上市指导价6.39万元起" |
| **禁极限词** | 最/第一/唯一/绝无仅有/领先同级等（除非官方发布口径且加引号） | ❌ "同级最强" ✅ "官方称同级唯一12扬声器" |
| **权益写截止时间** | 限时权益必须标注时间范围 | "至2026年9月30日24:00" |
| **引用第三方数据注明来源** | 销量、口碑、实测数据要写来源 | "懂车帝口碑评分 4.5 分（数据来源：懂车帝）" |
| **不确定的写"官方暂未公布"** | 不编造、不猜测 | 参数缺失时使用 |

## 用词规范

### 推荐
- 具体数字、具体场景："一周一充"、"一顿饭的功夫"、"4.9 米转弯半径，胡同掉头不尴尬"
- 产品逻辑分析："技术平权"、"把激光雷达下放到 8 万级"
- 克制的对比："比同级普遍多 100km 续航"
- 口语化解读："说白了""翻译一下""换句话说"

### 禁用（AI 味 + 营销雷区）
- 形容词堆砌：惊艳、颠覆、震撼、遥遥领先、天花板、降维打击
- 空泛排比："不仅……更……还……" 连用三次以上
- AI 高频词：此外、值得注意的是、总的来说、赋能、彰显、标志着
- 无来源的夸大："行业领先""同级最佳"
- 感叹号轰炸、emoji 装饰标题

## 长度与配图

- **正文**：上市新闻型 1200-2000 字（信息密度高，不注水）；导购/体验型可到 2500 字
- **配图**：15-30 张实车图（外观多角度、内饰、细节、空间），每张图配图注（一句话说明这是哪、展示什么）
- **图片原则**：**官网官方图优先**（car-official.ts，带语义分类 `descriptions.json`），抓不到再回退汽车之家/懂车帝；不用 AI 生图画车
- **封面**：实车高清图 + 标题文字（2.35:1 或 1:1）

## 示例片段

### 差 ❌（AI 味 + 空泛）
> 零跑A05的上市，标志着零跑汽车在智能电动汽车领域迈出了坚实的一步。这款车型不仅拥有令人惊艳的外观设计，更搭载了行业领先的智能座舱系统，为用户带来前所未有的驾乘体验，彰显了零跑对技术创新的执着追求。

### 好 ✅（参数 + 解读 + 克制点评）
> 零跑A05在杭州正式上市，售价6.39万元起，共5款版型。
>
> 这台车的思路很直接：尺寸不大，但把智能配置往里塞。8295P 座舱芯片、14.6 英寸 2.5K 中控屏、可选激光雷达——这些以前是 15 万以上车型的配置，现在 8 万出头就能选到。
>
> 动力上提供 70kW 和 90kW 两套电驱，CLTC 续航 405km 和 510km 两个版本。充电是亮点，30% 充到 80% 只要 16 分钟——周末跑个长途，服务区吃碗面的功夫，电就补得差不多了。
