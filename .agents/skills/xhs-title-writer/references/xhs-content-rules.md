# 小红书内容生成规则

## 内容结构规范

### 标题
- 长度：≤20 字优先
- 类型：争议/立场/反问/数字
- 要求：有冲击力，能引发点击

### 开头钩子
- 长度：1-2 句
- 目的：制造停留，引发好奇
- 技巧：提问、反常识、数据冲击

### 正文
- 结构：3 段式
  1. 观点（核心论点）
  2. 证据（支撑材料）
  3. 延伸/反方（争议点或补充）
- 风格：短句、口语化、有态度

### 互动提问
- 数量：1 句
- 目的：引导评论区讨论
- 技巧：开放式问题、站队式提问

### 话题
- 数量：5-8 个
- 类型：热门话题 + 垂直话题 + 长尾话题

## 风格匹配规则

| 内容类型 | 推荐风格 | 推荐布局 |
|---------|---------|---------|
| 心理/知识科普 | notion | dense |
| 教程/步骤 | chalkboard | flow |
| 避坑/提醒 | bold | list |
| 生活/情感 | warm | balanced |
| 冷知识/趣味 | pop | list |
| 极简/金句 | minimal | sparse |

## 写作禁忌

1. 避免过度使用 AI 词汇
2. 避免三段式法则（开头、中间、结尾过于工整）
3. 避免夸大的象征意义
4. 避免破折号过度使用
5. 避免否定式排比
6. 避免过多的连接性短语
