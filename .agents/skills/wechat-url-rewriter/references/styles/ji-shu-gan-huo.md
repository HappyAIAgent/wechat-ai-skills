# 技术干货风格规范

## 核心特点
直击痛点，给出可落地的解决方案和操作步骤，让读者学完就能用。

## 语气特点
- **专业**：用准确的技术术语，不回避专业词汇
- **精炼**：不说废话，每句话都有信息量
- **直接**：问题→方案→步骤，不绕弯子
- **自信**：对解决方案有把握，不模棱两可

## 结构要求

### 开头（问题导向）
- 直接点明要解决的问题
- 说明这个方案的价值/收益
- 示例开头：
  - "你是不是也遇到过 XX 问题？本文给出解决方案。"
  - "想实现 XX 功能？这篇教程带你从 0 到 1。"
  - "XX 工具的 YY 功能，很多人不知道怎么用。"

### 正文（步骤清晰）
- 使用编号列表展示步骤
- 每个步骤配代码示例或截图
- 关键配置用表格展示
- 注意事项用 ⚠️ 标记

### 结尾（总结+扩展）
- 核心步骤回顾
- 常见问题 FAQ
- 进阶资源链接

## 用词偏好

### 推荐
- 精确的技术术语：API、SDK、配置项名称
- 动作词：安装、配置、运行、部署、调用
- 代码相关：命令、参数、返回值、异常
- 版本信息：具体版本号、兼容性说明

### 避免
- "简单"、"容易"、"快速"等模糊词（除非真的简单）
- "据说"、"可能"、"大概"等不确定表达
- 大段理论解释（除非必要）
- 情感化表达

## 示例片段

### 差 ❌
> 首先我们需要安装这个工具，然后进行一些配置，最后就可以使用了。具体步骤如下：

### 好 ✅
> ## 安装
>
> ```bash
> npm install -g @anthropic-ai/claude-code
> ```
>
> ## 配置
>
> 在项目根目录创建 `.claude/settings.json`：
>
> ```json
> {
>   "permissions": {
>     "allow": ["Read", "Write", "Bash"]
>   }
> }
> ```
>
> ## 验证安装
>
> ```bash
> claude --version
> # 输出: claude-code 1.0.0
> ```
