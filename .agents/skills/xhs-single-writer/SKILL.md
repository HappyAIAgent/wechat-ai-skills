# 小红书单图笔记生成器

## 描述
本技能是小红书笔记的内容生成器，专注于**单封面图**场景。它编排整个内容生产流水线：从用户的一句话选题/描述出发，逐步产出带一张封面图的小红书笔记内容。

**适用场景**：
- 只需要一张封面图的笔记（如金句、极简风格）
- 图文分离型笔记（封面图吸引点击，正文纯文字）
- 快速出图，不需要多张卡片系列

**注意**：本技能只生成内容，不负责发布。如需发布，请配合 `xiaohongshu-ops` 技能使用。

## 工作流全景

```
用户输入 "写一篇关于XXX的小红书笔记"
  │
  ├─ Step 1: 解析输入 → 确定输出目录名 + 模式
  ├─ Step 2: 写稿 → 生成完整的小红书文案 + 封面图提示词（--fast 模式跳过）
  ├─ Step 3: 确认 → 用户确认文案（--no-confirm 跳过）
  ├─ Step 4: 出图 → baoyu-image-gen 生成 1 张封面图
  ├─ Step 5: 压缩 → baoyu-compress-image 压缩至 WebP
  └─ Step 6: 结构化输出 → summary.md + 输出目录
```

## 输出目录
所有产物统一放在 `image-cards/{YYYYMMDD_标题简称}/` 目录下：
```
image-cards/{YYYYMMDD_标题简称}/
├── source.md               ← 用户原始输入
├── summary.md              ← 结构化发布文案
├── cover-prompt.md         ← 封面图提示词
├── cover.png               ← 原始封面图
└── cover.webp              ← 压缩后封面图
```

**命名规则**：`YYYYMMDD_标题简称`
- `YYYYMMDD` = 当天日期（如 `20260802`）
- `标题简称` = 从文案主标题中提取 2-6 个汉字的核心关键词（如「手机幻觉震动」）
- 示例：`20260802_手机幻觉震动`
- `--fast` 模式下从用户输入中提取标题关键词
- **默认模式**：Step 1 先用用户输入生成临时目录名 `YYYYMMDD_{输入关键词}`，Step 2 写完稿后用主标题替换关键词部分（如有变化则重命名目录）

## 参数说明
| 调用方式 | 示例 |
|---------|------|
| 位置参数 | `/xhs-single-writer 写一篇关于幻觉震动的小红书笔记` |
| `--prompt` | `/xhs-single-writer --prompt "写一篇关于..."` |
| `--no-confirm` | 跳过确认步骤，直接生成 |
| `--style` | 指定封面风格（minimal/bold/hand-drawn/warm/cold 等） |
| `--fast` | 跳过写稿步骤，直接用用户描述出图 |
| `--no-images` | 只生成文案，不生成图片 |
| `--aspect-ratio` | 图片比例（默认 3:4 竖版） |

## 依赖的子技能（按调用顺序）
- `baoyu-image-gen` — 封面图生成（支持 7 个提供商、参考图、比例控制）
- `baoyu-compress-image` — 图片压缩（PNG → WebP）

## 工作流程

### Step 1: 解析输入

从用户消息中提取以下内容：

| 来源 | 提取方式 |
|------|---------|
| `--prompt "..."` | 取 `--prompt` 后面的全部内容 |
| 位置参数 | 取第一个非选项字符串参数 |
| `{输出目录名}` | `YYYYMMDD_标题简称` 格式（如 `20260802_手机幻觉震动`）。默认模式 Step 1 先用输入关键词生成临时名，Step 2 后用主标题替换；`--fast` 模式直接从用户输入提取 |
| `--style` | 指定封面风格 |
| `--fast` | 跳过写稿步骤，直接用用户描述出图 |
| `--no-images` | 只生成文案，不生成图片 |
| `--no-confirm` | 跳过确认步骤 |
| `--aspect-ratio` | 图片比例（默认 3:4） |

### Step 2: 写稿（`--fast` 模式跳过）

根据用户输入的选题描述，生成完整的小红书笔记文案：

**产出内容**：
1. **标题**（3-5 个备选，≤20 字优先）
2. **开头钩子**（1-2 句，制造停留）
3. **正文**（3 段式：观点 → 证据 → 延伸/反方）
4. **互动问句**（1 句，引导评论区）
5. **话题**（5-8 个）
6. **封面图提示词**（用于 baoyu-image-gen 生成封面）

**写稿原则**严格按照小红书平台风格：
- 短句 + 换行，口语化
- 有观点、有态度、不中立
- 少解释，多断言
- 保留可追问点用于评论区

**封面图提示词生成原则**：

封面图提示词需要写入 `cover-prompt.md` 文件，格式如下：

```markdown
# 封面图提示词

## 主题
[从文案中提取的核心主题]

## 风格
[根据 --style 参数或自动推荐的风格]

## 画面描述
[详细的画面描述，包含主体元素、构图、氛围]

## 配色
[主色调和辅助色]

## 文字（可选）
[如果需要在图片上显示文字，写明内容和位置]

## 比例
[默认 3:4 竖版，或用户指定的比例]
```

**风格自动推荐规则**：

| 内容类型 | 推荐风格 | 风格描述 |
|---------|---------|---------|
| 金句/极简 | minimal | 纯色背景 + 大字标题，干净利落 |
| 避坑/警告 | bold | 撞色、高对比、视觉冲击 |
| 知识/科普 | hand-drawn | 手绘风、趣味插画 |
| 生活/情感 | warm | 暖色调、柔和、亲切 |
| 科技/冷静 | cold | 冷色调、简洁线条 |
| 潮流/年轻 | pop | 鲜艳、活力、流行元素 |

**保存**：
- 用户原始输入 → `source.md`
- 封面图提示词 → `cover-prompt.md`
- 完整文案 → 后续步骤供出图时使用

**目录名更新**：Step 2 产出主标题后，从标题中提取 2-6 字关键词作为标题简称。若与 Step 1 临时目录名中的关键词不同，重命名输出目录为 `YYYYMMDD_{新标题简称}`。

**用户干预点**：文案产生后告知用户，用户可修改。确认后进入下一步。

### Step 3: 确认（`--no-confirm` 模式跳过）

呈现以下信息给用户确认：

```
📋 内容预览
标题：[主标题]
正文：[前 3 行...]

🎨 封面图方案（自动匹配）
风格：[minimal/bold/hand-drawn/...]
比例：[3:4 竖版 / 其他]
描述：[画面简述]

❓ 确认生成？
A) 确认 — 按当前方案生成
B) 修改 — 调整文案或封面风格
```

用户确认后进入 Step 4。

### Step 4: 出图（`--no-images` 模式跳过）

调用 `baoyu-image-gen` 技能生成封面图：

1. 读取 `cover-prompt.md` 中的提示词
2. 根据提示词构建完整的生图提示
3. 调用 `baoyu-image-gen` 生成图片
4. 产出文件为 `image-cards/{YYYYMMDD_标题简称}/cover.png`

**生图参数**：
- 比例：默认 `3:4`（小红书竖版），可通过 `--aspect-ratio` 覆盖
- 提供商：优先使用 `.baoyu-skills/.env` 中配置的 API 密钥对应的提供商

**参考图支持**：
- 如果用户提供了参考图（`--ref`），传递给 `baoyu-image-gen`
- 参考图用于提取风格、配色或构图

### Step 5: 压缩（`--no-images` 模式跳过）

调用 `baoyu-compress-image` 技能压缩生成的封面图：

- 如果生成的图片是 **PNG 格式** → 压缩为 **WebP 格式**
- 如果是其他格式 → 保持原格式，仅压缩
- 压缩质量：`--quality 80`
- 压缩后保存为 `image-cards/{YYYYMMDD_标题简称}/cover.webp`
- 压缩后清除原始大图（以 cover.webp 为准）

### Step 6: 结构化输出

将完整的小红书文案结构化输出到 `summary.md`：

```
image-cards/{YYYYMMDD_标题简称}/summary.md
├── 标题（主选 + 备选）
├── 开头钩子
├── 正文（3 段）
├── 互动提问
├── 话题（5-8 个）
├── 封面图说明
└── 封面图路径（cover.webp）
```

## 图片质量策略

| 使用场景 | quality | 格式 |
|---------|---------|------|
| 出图（baoyu-image-gen） | 默认 | PNG（默认） |
| 压缩后 | 80 | WebP（PNG→WebP）或 原格式 |

## 快速开始示例

```bash
# 一句描述自动完成全部流程
/xhs-single-writer "为什么口袋里的手机，总让你觉得它震了？"

# 指定 prompt
/xhs-single-writer --prompt "写一篇关于现代人手机幻觉震动的科普"

# 指定封面风格
/xhs-single-writer "选题" --style bold

# 快速模式（跳过写稿，直接用描述出图）
/xhs-single-writer "选题" --fast

# 只生成文案，不生成图片
/xhs-single-writer "选题" --no-images

# 跳过确认步骤
/xhs-single-writer "选题" --no-confirm

# 指定图片比例（正方形）
/xhs-single-writer "选题" --aspect-ratio 1:1
```

## 与 xhs-title-writer 的区别

| 特性 | xhs-single-writer | xhs-title-writer |
|------|-------------------|------------------|
| 图片数量 | 1 张封面图 | 5-7 张卡片系列 |
| 出图技能 | `baoyu-image-gen` | `baoyu-xhs-images` |
| 适用场景 | 金句、极简、图文分离 | 知识卡、教程、系列内容 |
| 输出结构 | 简单（单图） | 复杂（多图卡片 + 大纲） |
| 生成速度 | 快 | 较慢（多图） |

## 注意事项
- 本技能是**内容生成器**，不直接处理图片生成或发布，而是调度已有子技能
- `--fast` 模式适用于用户已有完整文案描述，只需出图的场景
- 默认模式（无 `--fast`）会先帮你写好完整的小红书文案，确认后再出图
- 生成的内容需要配合 `xiaohongshu-ops` 技能才能发布到小红书
- 封面图生成本身耗时较长，生图期间如有并行需求，优先结束当前步骤再响应

## 后续使用
生成的内容可以通过以下方式发布：
1. **手动发布**：复制 `summary.md` 内容，手动发布到小红书
2. **配合 xiaohongshu-ops**：将生成的内容作为输入，调用 xiaohongshu-ops 的发布功能
3. **导出到其他平台**：根据需要调整格式，发布到微信公众号、微博等
