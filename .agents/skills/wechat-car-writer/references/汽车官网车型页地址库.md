## 维护提示

1. **极氪 / 深蓝 / 启源**：中国站为 SPA（纯 HTTP 抓 HTML 只有壳，无实车图），采集需无头浏览器渲染；极氪可改用全球站 `https://www.zeekrlife.com/global/vehicles/001`（服务端渲染含实车图）
2. **比亚迪**：车型页分王朝网（`dynasty-home/models/...`）和海洋网（`ocean-home/models/...`），注意路径归属；`王朝` / `海洋` 系列首页条目在映射表中置于具体车型**之后**作兜底，避免 `王朝汉L` 被系列名抢先匹配
3. **丰田 / 本田 / 日产**：主站车型页多跳首页或无效，真实车型页在合资子站（广汽丰田 / 广汽本田 / 东风本田 / 东风日产）
4. **奥迪**：A4L/A6L 在一汽官网 `audi.cn`，Q5L/Q5 e-tron 在上汽官网 `audichina.cn`
5. **小米**：官网为 Next.js SPA，实车图在 `s1.xiaomiev.com/activity-outer-assets/...` CDN
6. **蔚来**：`nio.cn` 有 WAF 限流（567），批量采集时需降频或加延迟
